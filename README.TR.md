# Job To-Do List

HTML, CSS ve JavaScript ile geliştirilmiş bir iş başvurusu takip uygulaması.

## Özellikler
- Şirket, pozisyon, son tarih, kategori ve öncelik bilgileriyle başvuru ekleme
- Kategoriye göre filtreleme (Applied, Interview, Offer, Rejected)
- Öncelik veya son tarihe göre sıralama
- Görevi tamamlandı olarak işaretleme / geri alma
- Tek tek veya toplu görev silme
- Renkli öncelik şeridi ve durum badge'leri
- Koyu / Açık mod desteği
- LocalStorage ile kalıcı veri saklama

## Kullanılan Teknolojiler
- HTML5
- CSS3 (Grid, Flexbox, CSS Variables)
- Vanilla JavaScript
- Google Fonts — Inter

## Canlı Demo
[Uygulamayı Aç](https://job-to-do-list.netlify.app/)

## Nasıl Kullanılır
1. Şirket adı, pozisyon, kategori, öncelik ve son tarihi gir
2. **Add Task** butonuna tıkla veya Enter'a bas
3. Filtre butonlarıyla kategoriye göre görüntüle
4. Sort By ile öncelik veya tarihe göre sırala
